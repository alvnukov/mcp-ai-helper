## Body

file action=search дважды за сессию вернул 0 совпадений на строках, гарантированно присутствующих в файлх (паттерны с альтернативой). Grounding-инструмент, дающий ложноотрицательный результат, хуже отсутствующего — модель доверяет пустому результату.

## Acceptance Criteria

- найдена и устранена причина пропуска совпадений (наблюдалось на паттернах с альтернативой a|b, дважды независимо за сессию ревью)
- тест на паттерны с |, группами и якорями
- поведение регистронезависимости/границ не меняется
